# Page Alarm

The **alarm page** and the **unlock page** derived from it are configured **in the admin only**.
A configuration script cannot create these card types — it rejects them explicitly
(„is only supported in the admin configuration! Skipped!"). So there is no second way here, and
accordingly no script description either.

➡️ **[Alarm and unlock page – configuration in the admin](PageAlarm-Admin)**

It covers: the operating mode *Alarm* / *Unlock*, the PIN, the eight buttons and their states,
*Approved*, the `unlock_global` checkbox, the target of the unlock page, and the three states
(`.status`, `.mode`, `.approve`) through which a real alarm system is connected.
