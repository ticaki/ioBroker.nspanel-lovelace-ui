# Testumgebung – Bilder

Alle Aufnahmen stammen aus der Web-Ansicht derselben Konfiguration, einmal je Panel-Modell. Sie zeigen, wie dieselben Seiten auf den fünf Formaten aussehen. Die Dateien liegen im Repository unter `doc/Pictures/testumgebung`. Wie die Konfiguration eingespielt wird, steht in [Testumgebung](Testumgebung).

> **Zu jedem Block führt ein Rücksprung an die Stelle der Hauptseite, von der er aufgerufen wird.**
